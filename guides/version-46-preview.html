二、真珠角色定位与机制简述

真珠是 5 星冰属性、欢愉命途、生存辅助角色，身份为星际和平公司石心十人之一、二相乐园 CEO，智械。中文 CV 苏婉 / 日文 CV 安野希世乃。

  • 核心机制：护盾 + 全队增益（欢愉体系），可显著提升队友行动频率与最终伤害
  • 适配队伍：欢愉战舰（真珠 + 火花 + 爻光 + 银狼 Lv.999）、4.7 虚照体系预备位
  • 与 SP 砂金的联动：SP 砂金主线调查的"内鬼"剧情节点可能由真珠上线时正式揭晓
一句话定位：真珠是欢愉命途目前唯一带护盾的全队增益辅助，体系玩家刚需；非欢愉队玩家本版本可观望。

三、抽取建议

玩家类型建议理由
欢愉战舰玩家0 命必抽，专武看预算真珠是体系最后一块拼图，缺她战舰强度差距明显
非欢愉队 / 中级玩家跳过，留星琼4.7 虚照 + 多角色复刻星琼压力更大

新手 / 月卡党观望为主建议先把 4.5 卡池（知更鸟·晴歌 / 砂金·戏浪）的资源消化完
平民替代：暂时没有欢愉生存位可用娜塔莎 / 杰帕德（通用护盾）过渡，真珠体系收益主要体现在"全队增益"，所以暂无完全下位替代。

四、4.6 复刻角色价值评估

绯英（首次复刻）

  • 定位：欢愉命途主 C / 输出核心
  • 复刻价值：缺绯英且要组 4.7 虚照队的玩家建议抽；纯闲角玩家可跳
  • T 队评级：T0（欢愉队）/ T1（其他体系）

千冶·刃

  • 定位：毁灭命途追击主 C，详见千冶刃配队攻略
  • 复刻价值：缺追击队的玩家可补，已有同类型可不抽
  • T 队评级：T1（追击队）/ T2（其他队伍）

遐蝶

  • 定位：存护/辅助位
  • 复刻价值：老角色高强度辅助，缺辅助位的玩家可补
  • T 队评级：T1（泛用辅助）

五、星琼规划（4.6 → 4.7）

4.6 + 4.7 是连续两个高强度星琼消耗版本（社区流传），需要至少做一次"取舍"。下面给出三种典型路径：

路径4.6 抽谁4.7 抽谁所需星琼参考
A. 欢愉战舰一路推到满真珠 + 绯英银狼 Lv.999 + 爻光≥ 240 抽（约 4 万星琼）
B. 虚照主力 + 备用只抽真珠（0 命）/ 跳过虚照 + 银狼 Lv.999≥ 180 抽（约 3 万星琼）
C. 平民月卡党跳过 / 0 命真珠虚照 0 命约 80 抽（1.4 万星琼）

路径 C 是大部分月卡党的稳妥选择；路径 A 适合氪金 / 屯钻党；路径 B 适合"等虚照"星人。月卡党建议4.6 跳过复刻，所有资源集中冲 4.7 虚照。

六、4.6 配队预览（真珠入队）

欢愉战舰（推荐）

真珠 + 绯英 + 火花 + 爻光 / 缇宝

  • 真珠承担护盾与全队增益
  • 绯英 / 火花作为主要输出
  • 爻光提供欢愉体系速度循环 / 缇宝走穿透易伤路线

低配过渡队

真珠 + 娜塔莎 / 三月七（护盾）+ 任一欢愉主 C + 同谐

  • BOX 较浅玩家的临时方案，等 4.7 银狼 Lv.999 / 爻光复刻到位再换

七、遗器 & 光锥前瞻

真珠的专属遗器套装与专武会随前瞻直播一并公布，本节会在 2026.09.20 前更新。预计方向：

  • 专武：护盾量 + 全队增益 / 欢愉体系速度加成
  • 套装：欢愉向新 4 件套，护盾量 + 行动频率
  • 下位替代：旧欢愉散件 + 通用治疗 / 护盾词条过渡

八、适用环境评价

  • 深渊（忘却之庭）：真珠提升欢愉队在混沌回忆的环境适应度，火花 / 绯英双 C 队伍满星更容易
  • 虚构叙事：欢愉体系继续大热，真珠护盾在连段场景下尤为重要
  • 开拓副本：不影响主要玩法节奏

九、总结

4.6 是一个"过渡 + 储备"版本：真珠填补欢愉战舰生存位，复刻池覆盖到追击、辅助、欢愉三个体系。本版本最大风险是 4.7 虚照 + 多个复刻同期上线导致星琼爆炸，建议普通玩家提前做好"4.6 跳复刻、4.7 集中抽虚照"的规划。

  • 欢愉队玩家：真珠必抽，复刻按需补
  • 非欢愉队玩家：本版本跳过，留资源冲 4.7
  • 氪金玩家：真珠 1 命 + 专武，再补 4.7 银狼 Lv.999
