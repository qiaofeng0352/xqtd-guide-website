星穹铁道黑天鹅配队遗器光锥图鉴

更新时间：2026.08.18 版本：4.5 定位：风系 · 虚无 · DOT主C

核心结论：黑天鹅是奥迹叠层机制的 DOT 主C，DOT 层数叠高后伤害爆炸。需要高频攻击引爆 DOT 的队友配合（卡芙卡最佳），是 DOT 体系双核之一。

一、角色定位

  • 属性/命途：风 · 虚无
  • 定位：DOT 主C / 副C，奥迹叠层输出
  • 核心机制：【奥迹】随敌方受到 DOT 次数叠层，层数越高伤害越高；效果命中提升叠层效率
  • 强度评级：T1（DOT队核心输出）

二、配队推荐

DOT队（毕业）

黑天鹅 + 卡芙卡 + 阮梅 + 藿藿

  • 卡芙卡引爆奥迹风化，协助叠层同时作为第二C输出
  • 阮梅增伤+加速+削韧效率，DOT 双 C 最佳辅助
  • 藿藿补充能缺口+提供攻击力；无藿藿用符玄

低配过渡

黑天鹅 + 桑博 / 桂乃芬 + 艾丝妲 + 娜塔莎 — 无卡芙卡时的平民 DOT 组合。

海瑟音强化版

黑天鹅 + 卡芙卡 + 海瑟音 + 砂金 / 风堇 — 海瑟音领域降防+易伤，DOT 队伤害上限再提升。

三、遗器搭配

推荐套装

  • 毕业外圈：幽锁深牢的系囚 4 件套（DOT 增伤+减防）
  • 内圈：沉欢醉饮的海隅 / 苍穹战线格拉默（高速）

部位推荐主词条
